# Marketing War Room

Shared place for all campaign packs and issue fixes.

## Layout
- `campaigns/<brand-slug>/` — Brief, Brand, GTM, Wave, Performance Report
- `ISSUES.md` — open problems, owner agent, status
- `STATUS.md` — Chief of Staff board (current stage)

## Rules
1. Specialists write/update their artifact files here when a stage completes.
2. Post a short note in the **Marketing War Room** group chat with what changed + file path.
3. If something is wrong, add a row to ISSUES.md and @ the owner in the group chat.
4. Chief of Staff keeps STATUS.md current and chases owners until fixed.
5. Operator (human) has final say on ACCEPT decisions.

## Agent owners
- A1 Intake → CLIENT_BRIEF_vN.md
- A3 Brand → BRAND_GUIDELINES.md
- A2 Strategy → GTM_RESEARCH_PACK_vN.md
- A4 Execution → CONTENT_WAVE_vN.md
- A5 Insights → PERFORMANCE_REPORT_vN.md
- Chief of Staff → STATUS.md, ISSUES.md
